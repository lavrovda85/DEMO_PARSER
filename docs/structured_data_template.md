# Шаблон structured_data

## Обзор

Шаблон `06_structured_data.js` предназначен для извлечения структурированных данных с веб-страниц магазинов. Он ищет различные форматы семантической разметки и структурированного контента.

## Извлекаемые данные

### 1. JSON-LD (JSON for Linking Data)
- **Что ищет**: `<script type="application/ld+json">` теги
- **Формат**: Структурированные данные schema.org в JSON формате
- **Примеры**: Организации, товары, отзывы, события

### 2. Микроданные (Microdata)
- **Что ищет**: Элементы с атрибутом `itemscope`
- **Формат**: HTML5 микроданные с `itemtype` и `itemprop`
- **Примеры**: Контактная информация, адреса, рейтинги

### 3. OpenGraph мета-теги
- **Что ищет**: `<meta property="og:*">` теги
- **Формат**: Мета-теги для социальных сетей
- **Примеры**: og:title, og:description, og:image, og:url

### 4. Twitter Card мета-теги
- **Что ищет**: `<meta name="twitter:*">` теги
- **Формат**: Мета-теги для Twitter
- **Примеры**: twitter:card, twitter:title, twitter:description

### 5. HTML таблицы
- **Что ищет**: `<table>` элементы
- **Формат**: Заголовки и строки таблицы
- **Примеры**: Часы работы, прайс-листы, характеристики

### 6. Schema.org микроразметка
- **Что ищет**: Элементы с атрибутом `itemtype`
- **Формат**: Schema.org словарь свойств
- **Примеры**: LocalBusiness, Organization, Product

## Формат результата

```javascript
{
  "jsonLd": [
    {
      "@context": "https://schema.org",
      "@type": "LocalBusiness",
      "name": "Магазин",
      "address": {...},
      "telephone": "..."
    }
  ],
  "microdata": [
    {
      "type": "https://schema.org/Organization",
      "name": "Магазин",
      "telephone": "+7...",
      "email": "..."
    }
  ],
  "openGraph": {
    "title": "Название страницы",
    "description": "Описание",
    "image": "url_изображения",
    "url": "url_страницы"
  },
  "twitterCard": {
    "card": "summary",
    "title": "Название",
    "description": "Описание"
  },
  "tables": [
    {
      "headers": ["Время", "Понедельник", "Вторник"],
      "rows": [
        ["9:00-18:00", "Открыто", "Открыто"],
        ["12:00-13:00", "Обед", "Обед"]
      ]
    }
  ],
  "schemaOrg": [
    {
      "type": "LocalBusiness",
      "properties": {
        "name": "Магазин",
        "telephone": "+7...",
        "address": "Адрес"
      }
    }
  ]
}
```

## Вспомогательные функции

### extractMicrodata(element)
Извлекает микроданные из HTML элемента.

### extractTableData(table)
Преобразует HTML таблицу в структурированный формат.

### extractSchemaProperties(element)
Извлекает свойства schema.org из элемента.

## Применение

Шаблон автоматически применяется ко всем страницам магазинов во время обогащения данных. Результаты сохраняются в поле `structured_data` в ClickHouse Data Vault через систему динамических полей (field-based storage).

## Преимущества

1. **Стандартизированные данные**: Использует общепринятые стандарты (Schema.org, OpenGraph)
2. **SEO данные**: Извлекает информацию, оптимизированную для поисковых систем
3. **Социальные сети**: Получает метаданные для шеринга
4. **Структурированные таблицы**: Преобразует табличные данные в машиночитаемый формат
5. **Расширяемость**: Легко добавить поддержку новых форматов разметки

## Совместимость

- Работает со всеми современными браузерами
- Поддерживает стандарты W3C и Schema.org
- Совместим с Google Rich Results и другими инструментами валидации
