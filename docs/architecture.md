# Архитектура Data Ingestion Pipeline

## Обзор системы

Data Ingestion Pipeline представляет собой ETL-систему для извлечения данных о розничных магазинах из Google Places API, их обогащения и сохранения в реляционную базу данных.

## Компоненты

### 1. Конфигурационный слой (`src/config.py`)

**Ответственность:**
- Загрузка настроек из переменных окружения
- Валидация конфигурации через Pydantic
- Предоставление единой точки доступа к настройкам

**Паттерны:**
- Singleton для глобального экземпляра настроек
- Settings classes для группировки связанных параметров

### 2. Слой данных (`src/models.py`, `src/database.py`)

**Ответственность:**
- Определение схемы базы данных
- Управление подключениями и сессиями
- Абстракция работы с PostgreSQL

**Паттерны:**
- Repository pattern через SQLAlchemy ORM
- Context manager для управления сессиями
- Factory pattern для создания подключений

**Модель данных:**
```python
Store:
  - id: UUID (PK)
  - name: String (indexed)
  - website: String (nullable)
  - phone: String (nullable)
  - address: Text (nullable)
  - place_id: String (unique, indexed)
  - description: Text (nullable)
  - created_at: DateTime
  - updated_at: DateTime
```

### 3. Слой интеграции с внешними API (`src/places_api.py`)

**Ответственность:**
- Взаимодействие с Google Places API
- Обработка пагинации результатов
- Нормализация данных из API

**Паттерны:**
- Adapter pattern для абстракции API
- Strategy pattern для различных типов запросов
- Error handling с graceful degradation

**Основные методы:**
- `search_places()` - текстовый поиск мест
- `get_place_details()` - получение детальной информации
- `normalize_place_data()` - нормализация для БД

### 4. Слой обогащения данных (`src/enrichment.py`)

**Ответственность:**
- Извлечение метаданных с веб-сайтов
- Обход защиты от ботов через Playwright или Stealth Puppeteer
- Асинхронная обработка запросов
- Конфигурируемый выбор библиотеки браузерной автоматизации

**Паттерны:**
- Async/Await для неблокирующих операций
- Strategy pattern для выбора библиотеки (Playwright/Pyppeteer)
- Stealth techniques для обхода защиты
- Fallback strategies при ошибках
- Configuration pattern через переменные окружения

**Конфигурация:**
- Выбор библиотеки через `ENRICHMENT_BROWSER_LIBRARY` (playwright/pyppeteer/auto)
- Headless режим через `ENRICHMENT_HEADLESS`
- Таймаут через `ENRICHMENT_TIMEOUT`

**Алгоритм извлечения:**
1. Выбор библиотеки на основе конфигурации
2. Загрузка страницы через выбранную библиотеку
3. Применение stealth режима (для Pyppeteer)
4. Извлечение мета-описания или основного контента
5. Обработка таймаутов и ошибок

### 5. Слой оркестрации (`src/main.py`)

**Ответственность:**
- Координация всех компонентов
- Управление потоком данных
- Обработка ошибок и логирование

**Паттерны:**
- Pipeline pattern для последовательной обработки
- Template method для стандартизации процесса
- Observer pattern через логирование

**Поток данных:**
```
1. Инициализация БД
   ↓
2. Поиск мест через Google Places API
   ↓
3. Нормализация данных
   ↓
4. Обогащение через веб-сайты (опционально)
   ↓
5. Сохранение/обновление в БД
   ↓
6. Логирование результатов
```

## Обработка ошибок

### Стратегии обработки:

1. **API ошибки:**
   - Retry с экспоненциальной задержкой
   - Graceful degradation (продолжение без обогащения)
   - Детальное логирование

2. **Ошибки БД:**
   - Rollback транзакций
   - Изоляция ошибок на уровне записи
   - Продолжение обработки остальных записей

3. **Ошибки обогащения:**
   - Таймауты для долгих операций
   - Пропуск недоступных сайтов
   - Сохранение базовых данных без описания

## Развертывание

### Docker Compose архитектура:

```
┌─────────────────┐
│   PostgreSQL    │
│   Container     │
└────────┬────────┘
         │
         │ Network
         │
┌────────▼────────┐
│  Python App     │
│  Container      │
│  - Places API   │
│  - Enrichment   │
│  - Pipeline     │
└─────────────────┘
```

### Переменные окружения:

- `POSTGRES_*` - настройки БД
- `GOOGLE_PLACES_API_KEY` - API ключ
- `SEARCH_*` - параметры поиска
- `ENRICHMENT_*` - настройки обогащения данных (библиотека, headless, timeout)
- `PIPELINE_*` - настройки параллелизма
