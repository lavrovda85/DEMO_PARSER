# Руководство по отладке

## Настройка отладки в VS Code

### Предварительные требования

1. **Установите Python extension для VS Code**
   - Откройте VS Code
   - Перейдите в Extensions (Ctrl+Shift+X)
   - Найдите "Python" от Microsoft и установите его

2. **Установите debugpy** (обычно устанавливается автоматически)
   ```bash
   python -m pip install debugpy
   ```

3. **Создайте файл .env** (если его нет)
   - Скопируйте `env.example` в `.env`
   - Заполните необходимые переменные окружения

### Конфигурации отладки

В проекте доступны следующие конфигурации отладки:

#### 1. Python: Debug Main Pipeline
Отладка основного модуля из `src/main.py`

#### 2. Python: Debug Main Pipeline (Root)
Отладка из корневого `main.py`

#### 3. Python: Debug Current File
Отладка текущего открытого файла

#### 4. Python: Debug Tests
Отладка всех тестов в директории `tests`

#### 5. Python: Debug Tests (Current File)
Отладка тестов в текущем файле

### Запуск отладки

1. Откройте панель отладки:
   - Нажмите `F5` или
   - Нажмите `Ctrl+Shift+D` или
   - Выберите "Run and Debug" в боковой панели

2. Выберите нужную конфигурацию из выпадающего списка

3. Нажмите `F5` или кнопку "Start Debugging"

### Установка точек останова (Breakpoints)

- Кликните слева от номера строки, чтобы установить точку останова
- Красная точка означает активную точку останова
- При запуске отладки выполнение остановится на установленных точках

### Решение проблем

#### Ошибка: "debugpy не найден"
```bash
python -m pip install debugpy
```

#### Ошибка: "Не удается найти файл .env"
- Убедитесь, что файл `.env` существует в корне проекта
- Или скопируйте `env.example` в `.env` и заполните значения

#### Ошибка: "Python interpreter не найден"
- Нажмите `Ctrl+Shift+P`
- Введите "Python: Select Interpreter"
- Выберите правильный интерпретатор Python

#### Отладка не запускается
- Проверьте, что Python extension установлен и активирован
- Перезапустите VS Code
- Проверьте, что файл, который вы пытаетесь отладить, существует

### Дополнительные настройки

Все конфигурации используют:
- **Интегрированный терминал** для вывода
- **Переменные окружения из .env** файла
- **PYTHONPATH** настроен на корень проекта
- **justMyCode: false** для отладки библиотечного кода
