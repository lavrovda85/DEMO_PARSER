# 📋 Changelog - Data Ingestion Pipeline

## [3.0.0] - 2025-12-21 - Major Release 🚀

### ✨ Новые возможности

#### 🎯 Динамические JavaScript шаблоны
- **Автоматическая загрузка** шаблонов из папки `src/extraction/templates/`
- **Порядок выполнения** по нумерации файлов (01_, 02_, etc.)
- **Расширяемость** - добавление новых полей без изменения кода
- **Примеры шаблонов**: description, contact, hours, address, social

#### 🗄️ ClickHouse Data Vault архитектура
- **Замена PostgreSQL** на ClickHouse для высокой производительности
- **Hub-Satellite-Link** структура для нормализованного хранения
- **Автоматическое расширение** схемы для новых полей
- **Историчность данных** с поддержкой версий
- **Оптимизированные запросы** через материализованные представления

#### 🎛️ Jupyter Аналитический Дашборд
- **Интерактивное управление** процессом сбора данных
- **Визуализация данных** на Plotly (рейтинги, контакты, статистика)
- **Мониторинг шаблонов** - просмотр активных JavaScript шаблонов
- **Реал-тайм аналитика** собранных данных
- **Сводная статистика** системы

#### ⚡ Параллельная инициализация Pipeline
- **Одновременный запуск** браузера и базы данных
- **Batch режим** с предварительной подготовкой ресурсов
- **Улучшенная производительность** запуска системы

### 🔧 Технические улучшения

#### Архитектура
- **Модульная структура** - все файлы < 200 строк
- **Чистый код** - удалены устаревшие файлы и код
- **Форматирование PEP8** - стандартизированный стиль
- **Оптимизированные импорты** - удалены неиспользуемые зависимости

#### Производительность
- **ClickHouse** для быстрого аналитического хранения
- **Data Vault** для эффективного хранения разреженных данных
- **Параллельная обработка** обогащения и сохранения
- **Semaphore контроль** нагрузки на ресурсы

### 🔄 API изменения

#### Новые компоненты
- `ClickHouseDataVaultClient` - клиент для Data Vault операций
- `ExtractionTemplates` - менеджер динамических шаблонов
- `DataExtractor.extract_all_fields()` - применение всех шаблонов

#### Измененные компоненты
- `PlacesIngestionPipeline` - поддержка параллельной инициализации
- `DataEnricher` - использование динамических полей
- `DataSaver` - ClickHouse Data Vault сохранение

### 📊 Data Vault схема

#### Hub таблицы
- `hub_stores` - магазины
- `hub_fields` - поля данных

#### Satellite таблицы
- `sat_store_attributes` - атрибуты магазинов
- `sat_field_values` - значения полей

#### Link таблицы
- `link_store_fields` - связи магазин-поле

#### Представления
- `vw_store_data` - удобное чтение данных
- `mv_store_search` - поиск по place_id
- `mv_field_stats` - статистика по полям
