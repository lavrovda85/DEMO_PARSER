# 📊 Jupyter Аналитическая Панель

Интерактивная среда для управления процессом сбора данных и анализа результатов.

## 🚀 Запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите Jupyter Lab:
```bash
jupyter lab
```

3. Откройте `store_analytics_dashboard.ipynb`

## 🎯 Возможности

### Управление сбором данных
- Настройка параметров поиска
- Выбор региона и категории магазинов
- Управление обогащением данных
- Мониторинг выполнения в реальном времени

### Аналитика и визуализация
- Распределение рейтингов магазинов
- Зависимость рейтинга от количества отзывов
- Статистика наличия контактных данных
- Динамические графики на Plotly

### Управление шаблонами
- Просмотр всех доступных шаблонов извлечения
- Информация о структуре шаблонов
- Автоматическая загрузка из папки `src/extraction/templates/`

### Сводная статистика
- Обзор конфигурации системы
- Статус подключений
- Параметры производительности

## 📁 Структура шаблонов

Шаблоны извлечения автоматически загружаются из папки `src/extraction/templates/`:

```
01_description.js    - Извлечение описания страницы
02_contact.js        - Контактная информация (email, телефон)
03_hours.js          - Часы работы
04_address.js        - Адрес
05_social.js         - Социальные сети
```

### Добавление нового шаблона

1. Создайте файл `NN_fieldname.js` в папке `src/extraction/templates/`
2. Напишите JavaScript код для извлечения данных
3. Перезапустите Jupyter ноутбук или вызовите `ExtractionTemplates.clear_cache()`

Пример шаблона:
```javascript
() => {
    // Ваш код извлечения данных
    const data = document.querySelector('selector');
    return data ? data.textContent.trim() : null;
}
```

## 🔧 Использование

1. **Настройка параметров**: В разделе "Панель управления" настройте параметры поиска
2. **Запуск сбора**: Нажмите "🚀 Запустить сбор данных"
3. **Мониторинг**: Следите за статусом в разделе "Статус выполнения"
4. **Анализ**: Изучите графики и статистику в разделах аналитики
5. **Управление шаблонами**: Просмотрите активные шаблоны извлечения
